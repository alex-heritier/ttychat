# Agents

This document describes the AI agents used in this project.

## About ttychat

ttychat is a terminal GUI (TUI) social media platform designed for developers to hang out and discuss topics.

**Project Structure:**
- `frontend/` - Terminal UI application
- `backend/` - API server

**Tech Stack:**
- Frontend: TypeScript using the `opentui` library
- Backend: AdonisJS (TypeScript Node.js framework)
- Database: SQLite

## Roadmap

**Phase 1: TUI Frontend** (Current)
- Build the terminal user interface using opentui

**Phase 2: Backend** (TBD - Do NOT implement)
- Backend development is planned but not yet ready for implementation

## Claude

Claude is an AI assistant that can help with various tasks including:

- Code analysis and understanding
- Software development and debugging
- Documentation generation
- Testing and quality assurance
- Code reviews and improvements
- Understanding the ttychat TUI architecture and opentui library

## Usage

Agents can be interacted with through various interfaces and can assist with development workflows, automation, and problem-solving tasks specific to building and maintaining this TUI social media platform.
